# 交互人机工学提升与 Preview 20261030.1 发布验收

本报告记录 Preview 20261030.1（commit `1f05aa68` 与 `04f71ec1`）的交互升级实现、设计对齐与质量门禁验证。

---

## 1. 背景与优化目标

在真实多 Agent 协作工作流中，操作员频繁在目标输入、指令调整、产物核验与敏感审批之间流转。前期版本重点打通了核心编排与单机协作闭环，但在高频日常使用中存在以下人机工学体验痛点：

1. **输入流转依赖鼠标**：每次键入目标或任务执行补充指令后，必须移开键盘点击按钮提交，打断极客连续输入心流。
2. **意外刷新/切换草稿丢失**：未提交的目标输入若遇页面意外刷新、浏览器标签关闭或切项目，未保存文本直接丢失。
3. **示例词覆盖已有输入**：点击“试试：分析问题 / 审查代码”等提示词时直接覆盖输入框，导致用户已构思文字被冲掉。
4. **代码成果审阅单调**：包含 Unified Diff 代码补丁的成果仅能以普通文本查看，缺乏行号分栏与增删色彩标注，难以快速审阅变更；缺少一键复制便捷操作。
5. **审批卡片安全风险不明显**：各类工具调用混杂，高危破坏性命令（终端执行、强制推送）与常规只读检索缺乏直观视觉分级，增加人工审核把关的心智负担。
6. **静态横幅警告抖动视口**：错误与状态提示以顶部固定横幅呈现，出现和关闭时推挤主对话区域，造成版面跳动。

---

## 2. 交互特性落地明细

### 2.1 高频输入人机工学优化

- **快捷键即时提交**：
  - 任务目标输入框（`#task-prompt`）与任务过程补充指令框（`.task-instruction-textarea`）均绑定 `onKeyDown` 监听器，检测到 `Ctrl+Enter` 或 `Cmd+Enter` 时自动触发当前可用的提交动作（开始协作 / 保存草稿 / 发送补充要求）。
  - 按钮附带 `title="支持按 Ctrl+Enter 快捷提交"` 引导提示，保持界面整洁且不破坏原有 E2E 严格匹配选择器。
- **目标草稿 LocalStorage 自动防丢**：
  - 采用以项目 ID 隔离的本地存储键值（`hermes:draft-prompt:<projectId>`）。
  - 用户键入时防抖/实时存入本地缓存；页面重新载入或在侧边栏切换项目时，自动优先恢复该项目的未完成草稿；在任务成功发起或显式保存为持久化草稿后自动清除。
- **示例提示词智能追加**：
  - 点击“试试：分析问题 / 审查代码”等推荐词时，若输入框已有文本，改为以双换行智能追加，避免覆盖用户构思内容。

### 2.2 交付产物富文本审阅与快捷复制

- **Unified Diff 代码变更自动高亮**：
  - 独立组件 `ArtifactContentViewer` 自动检测交付产物的元数据类型（`kind === 'diff'`）或正文特征（包含 `diff --git`、`@@ ... @@` 语法块）。
  - 解析 Unified Diff 语法，生成行号双列分栏，高亮区分新增行（绿色背景与字体）、删除行（红色背景与字体）及定位块（青色），使代码改动审阅清晰直观。
- **一键复制交付产物**：
  - 在成果预览卡片右上角新增快捷复制按钮，通过系统剪贴板 API 复制全文，并提供 2 秒“已复制 ✓”的视觉动效反馈。

### 2.3 审批流安全风险智能分级

- **三级风险徽章标识（Risk Badges）**：
  - 统一风险计算逻辑 `getApprovalRiskLevel()`：
    - 🔴 **高危操作（Danger）**：涉及系统命令（`run_command`、`execute`、`bash`、`terminal`）、终端执行、破坏性删除等；
    - 🟡 **写入变更（Warning）**：涉及文件覆写（`write_file`、`edit_file`）、合并（`merge`）、推送（`push`）等；
    - 🔵 **常规只读（Info）**：涉及文件检索、状态检查等；
  - 在审批卡片与列表详情中醒目展现风险标识，帮助操作员一眼辨识操作边界。

### 2.4 轻量浮动 Toast 通知体系

- **零外部依赖自研**：
  - 构建轻量全局 Toast 状态机与组件，支持 `success`、`error`、`info` 等反馈类型。
  - 悬浮于视口右上角（`z-index: 1000`），4 秒后自动淡出消失，并支持单条手动关闭。
  - 彻底杜绝顶部静态警告横幅推挤主界面布局引发的视口抖动问题。

### 2.5 架构全景白皮书（ARCHITECTURE.md）

- 梳理并提交了 `ARCHITECTURE.md` 技术参考白皮书，涵盖：
  - 架构设计不变式与模块分层拓扑图
  - 核心领域数据模型契约（Task / Assignment / Attempt / Artifact / Policy / Approval）
  - ACP 协议交互生命周期与会话挂载状态机
  - 策略审批控制模型与执行边界定义
  - 多工作区管理与性能演进路线
