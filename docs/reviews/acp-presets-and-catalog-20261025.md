# ACP 常用方案、能力观察和接入来源

2026-10-25，承接 `acp-session-settings-20261025.md` 的两成员真实改码与追问验收。本批继续改现有成员抽屉和运行设置弹窗，不新建配置页面，也不安装新的 Agent。

## 本批行为

- 每位成员可保存多个命名常用方案。选用先载入参数草稿，明确用于下次发送才应用；成员默认保持独立。管理项默认折叠，支持重命名、归档与恢复。
- 新任务首次接收时复制方案参数及其 ID、名称、版本。之后修改或归档方案不会改变已接受任务；重试不重新读取方案。追问默认继承上一轮实际确认值，显式方案只影响新轮次。
- 网页和 MCP 共用服务。MCP `list_agents` 返回有界方案摘要；`submit_task` 与 `continue_task` 可用 `sessionPresetId`，与 `sessionSettings` 互斥。没有新增模型提示、权限或委派角色。
- 能力观察绑定成员配置摘要、可观察就绪证据、探针会话摘要和时间，五分钟后过期。失败保留旧观察但标记失效；仅读取页面不会启动 Agent。保存参数需显式核对，已有保存结果的相同请求确认不需要重新探针。
- ACP 没有暴露账号身份，界面明确说明该限制；就绪证据不等于账号身份识别。也没有将能力缓存、上下文容量和模型 KV 缓存混为一谈。
- 目录产品分别显示用户关联的成员、本机入口观察与就绪数量。当前显示项的检查仅查询有界文件元数据，不执行、认证或安装程序。常用位置未发现时允许选择其它目录，不宣称全机未安装。
- 来源只记录用户选择的目录产品、版本和入口摘要；旧名称匹配只表示“可能相同”，需显式关联。入口改动后来源标记为已变更，不修改登录、成员资格或权限。新注册和关联使用目录版本与成员版本确认。

## 持久状态与边界

新增第 17 次迁移 `0016_agent_session_presets` 和第 18 次迁移 `0017_agent_catalog_sources`。两套仓储位于接口之后；含旧库升级、重开、成员隔离、版本冲突、删除级联及坏数据拒绝覆盖。方案有 32 个启用、128 个总记录的限制，不将大量参数全文塞入 MCP 发现响应。

项目自动文件审批、命令与越界询问、人工审阅合并保持原样。来源关联不是程序签名、供应商身份认证或执行授权；LocalRunner 与工作树仍不是系统安全沙箱。
