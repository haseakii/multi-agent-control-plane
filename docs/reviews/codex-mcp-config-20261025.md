旧私有更新脚本用 `\s*$` 替换整段匹配，存在将节前行尾换行一并吃掉的问题。已新增 `scripts/lib/codex-mcp-config.mjs`，逐行替换仅允许的 `command` 和 `args` 值，原样保留行结束符、缩进、注释及其它表。两份旧私有更新脚本改为复用此函数。

4 项聚焦回归覆盖 LF、CRLF 下紧邻 `[windows]` 的节边界、BOM/注释/其它配置保留、配置已变化或格式歧义时拒绝重建。实际用户配置执行无写入 dry-run，输出与原始字节完全相同；随后再次完整 TOML 解析通过。没有改动 Windows 沙箱、其他 MCP、项目授权、连接文件或凭据。

后续更新 Codex 配置须复用此函数，并在用户已有 TOML 解析器中检查整个文件；不得再用跨行 `\s*` 直接拼接节文本。本修复不涉及工作台服务，不需要重新发布或重启服务。
