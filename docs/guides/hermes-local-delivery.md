# Hermes 本地可用版

2026-10-23 已完成真实 Codex / Antigravity 协作写页面、同一会话追问改代码、文件审阅合并与工作台交互预览。最新同页流程、简化 ACP 接入和短报告交接证据见 [日用流程验收](../reviews/hermes-daily-flow-20261023.md)，此前记录见 [真实代码页面验收](../reviews/hermes-real-code-page-20261023.md)。当前入口为 `http://127.0.0.1:8057/`，根目录双击 `启动工作台.cmd`；也可从 Codex 的 `local_collaboration` MCP 发起任务。`start-hermes.cmd` 及 integration 目录内的 `.cmd` 启动入口也复用 8057 日用实例；只有显式调用历史 PowerShell 开发脚本才会使用 8047。MCP 期间对日用数据完成了受控复制恢复，原件、旧包和旧锁均保留，当前路径见下文。

## 直接使用

1. 直接在 Codex 发起协作任务，`local_collaboration` 在首次调用时自动启动后台引擎。网页入口仍为 `http://127.0.0.1:8057/`；双击 `启动工作台.cmd` 也会启动或复用后台实例并打开网页，窗口可关闭。
2. 在首页选择“直接交给成员”或“由负责人安排协作”，确认执行成员与工作目录，再输入实际目标。执行方式和成员选择会保留；不会在成员不可用时悄悄替换成另一位。“工作目录”可选择已有项目、关联本机目录或新建空目录。
3. 点击“发送”或按 Ctrl+Enter，Enter 换行。执行中可在同一输入框补充要求，并通过右侧“过程 / 文件改动 / 页面预览”查看执行情况。顶部“使用说明”可随时打开流程指引，并直接进入成员管理或当前任务过程。
   独立 Git 任务的“文件改动”顶部会自动读取当前改动，点击文件默认突出显示增删行，保留附近上下文，可用“上一处 / 下一处改动”定位，也可切换完整内容对照。支持暂停和恢复更新，无需先生成快照。链接、子模块、大文件或未能读取的文件会标为尚未比较；实时内容不用于批准合并。
   多文件审阅可按路径搜索或按新增、修改、删除筛选，再用“上一个文件 / 下一个文件”逐项查看。筛选不会改变已打开的差异，也不会缩小批准或合并范围：批准仍针对整份固定快照。
4. 完成后在同一会话底部继续追问，历史目标和结果自动关联；新任务使用左侧按钮。
   编码任务点击“页面预览”，页面直接显示在对话旁。HTML、CSS、JavaScript 模块保存后自动更新，无需生成页面快照；支持暂停自动更新、手动刷新与手机宽度。切换“过程 / 文件改动”再返回预览会保留页面当前交互状态。通过“文件改动”生成固定差异，审阅、批准后确认合入源目录；后续轮次在此版本基础上继续。“过程”中可查看实际带入的前文、项目记忆和 Agent 上报的上下文与缓存。
5. 对话顶部“权限”可设置本项目的自动文件审批、命令确认/拒绝、工作区外访问、合并及推送。默认为逐次确认，推送禁止。自动文件审批仅限完整识别的独立工作区文件请求，逐条记录策略版本；敏感路径、共享目录及未知操作仍需确认。只控制已上报的请求，不保证隔离 Agent 自有工具。
6. 需要停机时运行根目录 `停止工作台.cmd`；下次 Codex 调用会自动重新启动。异常退出后，仅在 Windows 确认原进程退出且锁身份完整时恢复同一目录；活跃或身份不明的锁仍保留。

无需重新填写现有成员配置。新增成员使用“协作成员 → 接入本机协作者”，从产品目录找本机入口，或粘贴带完整路径的启动命令、批量 JSON；预览后点击“接入所选成员”。快速接入会注册、启用并检查 ACP 连接，手动详细配置先保存为停用。登录由成员卡片继续处理；同一产品的已登记入口可直接定位，失败项可单独重试或暂时跳过。批量接入中单项超时后会保留该项状态并继续后续成员；保存回复丢失时先核对已有配置，不主动重复注册。暂停在当前项返回结果或等待超时后生效。可明确勾选负责人资格，详细权限和启动参数保留在高级编辑中。只使用已安装程序，不执行安装命令，也不导入环境变量值或登录凭据。

任务中的“过程”面板可按轮次查看，分类按钮直接定位执行状态、上下文与记忆、成员交接、工作目录和时间线。面板只读取当前会话的过程记录；失败和中断保留在关键进展中，常规工具、回复和用量记录可展开查看。

产品目录和本机入口查找超过 15 秒未返回时会结束等待并给出重试入口。也可主动“停止等待查找”，继续手动填写程序和参数，或返回选择其他产品。停止等待只取消本次页面读取，不表示后台查找已停止；已填内容和此前查找结果仍保留，查找本身不会注册或启动成员。

配置编辑草稿和待接入列表保存在当前标签页；浏览器无法保存时页面会提示。保存若遇到回复丢失，会只读核对完整配置是否已保存；另一处修改了成员配置时，旧编辑不会覆盖新设置，可以读取最新配置、核对双方修改的字段后再保存。连接失败与登录失效分开显示，任务失败也不会伪装成已完成。检查连接若一直收不到网页回复，30 秒后会结束等待；登录确认保留最多 5 分半钟。超时只表示结果尚未确认，不会自动重复发起操作或断言后台已停止；请先查看登录窗口和刷新状态。操作前读取任务状态若超过 15 秒，则不会发起连接或登录。

个人启动器只引用已安装的适配器及既有登录目录，在子进程环境中设置路径；不复制登录凭据。启动时确认已有登录、不发送模型提示；登录失效时在“协作成员”中处理，由本人完成交互登录。重复打开会验证同一构建后打开现有实例。

2026-10-23 登录状态修复：普通“检查连接”的 ACP 握手若只返回登录状态未知，会保留本次服务运行中、同一注册配置已确认的登录结果，不再将已登录成员重置为待登录。Agent 明确要求登录、配置发生变更、连接或认证失败时仍按实际结果处理；连接检查不会自动发起认证或模型提示。

## 备份和恢复

先运行 `停止工作台.cmd` 正常停机，再用随包 node 执行 `apps/server/dist/release-main.js backup --config ABSOLUTE_CONFIG --output NEW_BACKUP_DIRECTORY`。恢复使用 `restore --backup BACKUP_DIRECTORY --output NEW_RESTORE_DIRECTORY`，随后检查生成的配置、端口和 Agent 外部路径。详细步骤及异常锁处理见随包 `RUN.txt`。备份含私有任务数据，应按本地私有资料保管。

旧 `state.sqlite` 的显式停机导出入口已实现，但本轮只验证新建模拟数据的标准备份恢复，没有迁移真实旧任务。旧 R2/R3/R4/R5 记录保留其当时的静态结论；不得将旧输入哈希当作当前最终包的哈希。

MCP 接入时首次后台启动进程随连接退出，留下异常锁；确认原进程不存在后，将原日用库和 WAL、产物复制到独立恢复目录，通过标准备份/恢复启动新副本。原 `.run/hermes-usable-20261023-r1/daily-data` 未删除或覆盖，旧任务工作区路径继续保留。恢复证据为 `.run/mcp-integration-20261023/recovery-evidence.json`。随后修正 Windows 后台进程生命周期，并验证客户端断开后服务仍存活，以及正常停止会释放实例锁。这里的恢复区别于早期 `state.sqlite` 迁移测试。

## 网页与外部 Agent 入口

产品方向保留网页独立使用，并让 Codex 等支持 MCP 的客户端连接同一协作引擎，共用任务、产物、过程和审阅记录。网页继续承担完整预览与人工审阅；MCP 提供提交、进度、结果和追问能力。只运行一个拥有数据目录锁的引擎实例，客户端连接器不分别打开数据库。

外部入口已实现，复用 `packages/fleet-mcp` 的独立 `client-stdio-main.js`，与内部 ACP 会话的 `stdio-proxy-main.js` 分开。客户端令牌、项目目录授权、工具权限及当前项目策略在每次调用时验证；目录授权基于已确认目录身份，跨正常服务重启保持有效，目录被替换时仍拒绝执行。外部客户端只连接现有引擎，不单独打开 SQLite。

本机 Codex 已登记 `local_collaboration`。可直接说：“查看可用项目和成员，让 Antigravity 审阅这个任务”“继续刚才的任务，增加……”。客户端先选择已授权项目与 Agent，再提交一次，使用返回的任务 ID 和游标查看增量进展；继续追问使用返回的最新任务 ID。网页同步显示任务、过程、产物及代码，静态页面预览仍自动更新。外部客户端负责协调直接委派；网页仍可使用原有 Boss/Worker 编排。

追问会携带持久化历史、结果引用和已接受项目记忆；未合并代码会复制到新任务工作区，Git 模式保留来源与累计审阅基线，原工作区和源目录不受修改。MCP 可生成固定文件差异，批准、合并及推送仍须由人在网页执行。不会自动导入当前 Codex 会话的全部聊天内容；缓存数值只展示 Agent 实际上报，不能承诺跨 Agent 共享缓存。

其他支持 stdio MCP 的客户端使用相同程序入口和一个独立客户端连接文件即可；目前实际客户端验收为 Codex 桌面端与 MCP SDK，未声称其他产品逐个实测。将下面的 `<当前 release 绝对路径>` 替换为启动器引用的实际目录，不要指向历史旧包：

```text
command: <当前 release 绝对路径>/runtime/node.exe
args:
  <当前 release 绝对路径>/node_modules/@control-plane/fleet-mcp/dist/client-stdio-main.js
  --connection
  <该客户端的私有连接文件绝对路径>
```

新增客户端时，运行已构建源码中的 `scripts/connect-mcp.mjs`，显式提供 `--url`、`--client`、`--project`、`--access-file` 和 `--connection`。只授权已有隔离项目，每个客户端使用独立令牌；脚本不安装依赖，也不复制提供商凭据。服务配置的 `clientAccessFile` 指向权限文件。协议支持可选 `start`，本机日用连接现已配置后台自动启动，正常使用无需先开网页或保留启动窗口。另接入的客户端是否自动启动取决于它的连接配置。服务异常或令牌失效时保留任务 ID，恢复连接后查询，勿盲目重复提交。
